ACT 2.2:
Supervisado: se tiene la tarea de observar ejemplos de entrada y salida, y a partir de ello, el agente se dedica a aprender la función que relaciona las entradas con sus salidas.
No supervisado: es un tipo de aprendizaje automático en el que un agente tiene la capacidad de identificar patrones y estructuras en los datos sin recibir retroalimentación explícita o etiquetas que guíen su proceso de aprendizaje.
Por refuerzo: es una técnica de aprendizaje automático que se centra en cómo un agente debe tomar decisiones en un entorno para maximizar una recompensa.

ACT 2.3
Pandas: Es una biblioteca de código abierto de python que funciona para la limpieza, la manipulación y preparación de datos 
Matplotlib: es una biblioteca de visualización de datos analizar modelos de Machine Learning
Scikit-learn: se utiliza para implementar algoritmos de Machine Learning
Google Colab: se utiliza para ejecutar y escribir códigos de Python directamente desde el navegador
Árbol de decisión: es un algoritmo de Machine Learning, como un diagrama de flujo o un mapa de reglas de decisión.
Matriz de confusión: Es una tabla bidimensional que se utiliza para evaluar el rendimiento de un modelo de clasificación estadístico
Sobreajuste: este ocurre cuando un modelo de Machine Learning aprende detalladamente datos de entrenamiento, en lugar de entender el patrón general
Falso Positivo: ocurre cuando un sistema afirma que encontró algo pero se ha equivocado.
Falso negativo: el sistema afirma que no encontró nada, pero se ha equivocado
